## Project Overview

This project covers a full 3-week cybersecurity internship task:

- **Week 1:** Security assessment of a vulnerable Node.js web app

| 2 | SQL Injection via login bypass | Critical | ✅ Fixed |
| 3 | Plain text password storage | Critical | ✅ Fixed |
| 4 | Weak session secret | Medium | ✅ Fixed |
| 5 | No input validation on signup | High | ✅ Fixed |
| 6 | No rate limiting on login | Medium | ✅ Fixed |

---

## Security Fixes Applied

- **Input Validation:** `validator` library on all user inputs
- **Password Hashing:** `bcrypt` with 10 salt rounds
- **JWT Authentication:** `jsonwebtoken` for token-based auth
- **HTTP Security Headers:** `helmet.js`
- **Rate Limiting:** `express-rate-limit` (10 attempts / 15 min)
- **Logging:** `winston` writing to `security.log`
- **XSS Prevention:** HTML escaping on all rendered user data
